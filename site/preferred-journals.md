# Preferred journals

Which journal entries to feature on the home page.

Add one entry per line, as a path relative to the repo root. Lines starting
with `#` are ignored. To override the displayed title, append `| your title`.

The site builder (`operations/tools/convert_posts_to_html.py`) reads this file
and regenerates `site/index.html`'s Journal section automatically.

# Examples (remove the leading # to feature them):
# record/journal/2026-08-18-2146-session-00173.md
# record/journal/2026-08-19-1428-session-00175.md | A day of small repairs
